# Cyprus Road Signs — Telegram Bot

Telegram-бот для подготовки к теоретическому экзамену на права на Кипре:
**234 знака в 13 категориях** + колода «экзаменационный минимум» (63 карточки с пояснениями).

## Что умеет

- **📚 Карточки** — изображение без подписи, «Показать ответ», затем «Дальше».
  Каждый просмотр отодвигает следующий показ: система Лейтнера, 5 коробок
  с интервалами 0 / 1 / 3 / 7 / 21 день.
- **✍️ Тест** — 10, 20 или все вопросы категории. Четыре варианта, неверные берутся
  из той же категории — так вопрос сложнее и полезнее. Ошибки возвращаются в повторение.
- Знаки, разметка и сигналы не смешиваются: вопрос формулируется по типу объекта,
  и варианты ответа подбираются только среди объектов того же типа.
- **📊 Прогресс** — сколько изучается и выучено, что пора повторить, последние 5 тестов.
- **⚙️ Настройки** — язык изучаемых названий: 🇬🇧 English или 🇬🇷 Ελληνικά. Название
  показывается только на выбранном языке — и в карточках, и в вариантах теста.

Команды: `/start`, `/cards`, `/quiz`, `/stats`.

## Шаг 0 — подготовка изображений

Изображения не хранятся в репозитории, их нужно подготовить один раз:

```bash
sudo apt install librsvg2-bin            # конвертер SVG (Linux)
brew install librsvg                     # то же самое на macOS
python3 scripts/fetch_images.py          # скачать 234 изображения → assets/img/
./scripts/convert_full_images.sh 512     # SVG → PNG (полный каталог)
./scripts/svg_to_png.sh 512              # SVG → PNG (колода-минимум) → assets/png/
```

После этого в `assets/img/` — 234 оригинала и 196 сконвертированных PNG,
в `assets/png/` — 63 PNG колоды-минимума.

## Токен

1. Написать [@BotFather](https://t.me/BotFather) → `/newbot` → имя и username бота.
2. Полученный токен вида `123456789:AA...` положить в `.env`:

```bash
cp .env.example .env    # затем вписать BOT_TOKEN=...
```

Бот работает в режиме long polling — публичный адрес и webhook не нужны.

## Запуск бота

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m bot.main
```

Через Docker (шаг 0 должен быть выполнен до сборки — изображения копируются в образ):

```bash
docker compose up -d --build
docker compose logs -f
```

В Kubernetes — манифесты и пояснения в [`deploy/`](deploy/README.md):

```bash
kubectl -n cyprus-signs-bot create secret generic bot-secrets \
  --from-literal=BOT_TOKEN='<токен>'
kubectl apply -k deploy/k8s/overlays/production
```

Прогресс пользователей лежит в `var/bot.db` (SQLite) и переживает пересборку образа —
каталог примонтирован томом.

## Устройство

| Модуль | Ответственность |
|---|---|
| `bot/main.py` | Точка входа, Dispatcher, роутеры, graceful shutdown |
| `bot/config.py` | Чтение `.env` / переменных окружения |
| `bot/cards.py` | Загрузка колод, интервалы Лейтнера, подбор дистракторов |
| `bot/db.py` | SQLite: `progress`, `file_cache`, `quiz_results` |
| `bot/media.py` | Отправка фото с кэшем `file_id` (файл уходит в Telegram один раз) |
| `bot/keyboards.py` | Inline-клавиатуры, callback-данные формата `c:<action>:<payload>` |
| `bot/handlers/` | `menu.py`, `flashcards.py`, `quiz.py` |
